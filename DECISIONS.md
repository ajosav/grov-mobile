# DECISIONS.md

The permanent record of decisions for grov_mobile. Nothing else goes in this file.

## Rules

- Append only. A row changes status once: Pending to Approved or Rejected. To reverse a decision, add a new row that cites the old one. Never edit a settled row.
- An agent writes `Approved` or `Rejected` only after the user says so in chat. A decision an agent made on its own is `Pending` until the user rules on it.
- Status is exactly Pending, Approved or Rejected.
- Source is `user` (said in chat), `PRD` (a cited requirement), or `agent` (proposed, needs ruling).
- One decision per row. IDs are M-001, M-002 and never reused. Product decisions D1–D40 live in `requirements/design/docs/00-context-and-decisions.md`, not here.
